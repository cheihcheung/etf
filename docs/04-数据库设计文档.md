## 2. 核心表结构

### 2.1 stock (ETF 基础标的与实时价格表)

**表说明**: 存储所有 ETF 标的元数据、实时行情价格、启用状态、专属加减比步长及初始配置权重。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | INT | - | AUTO | 主键 ID |
| code | VARCHAR | 20 | - | ETF 交易代码(唯一索引) |
| name | VARCHAR | 100 | - | ETF 名称 |
| asset_type | VARCHAR | 50 | - | 资产类型(股票类/债券类/红利类/商品类/黄金类) |
| current_price | DECIMAL | 12,4 | 0.0000 | 当前最新价格 |
| change_pct | DECIMAL | 10,4 | 0.0000 | 实时涨跌幅(%) |
| initial_ratio | DECIMAL | 10,4 | 0.0000 | 初始配置比例(%) |
| is_enabled | TINYINT | 1 | 1 | 是否启用该标的（0为禁用，1为启用，被禁用的标的从策略微调与回测中物理剔除） |
| step_ratio | DECIMAL | 5,2 | 5.00 | 每档加减比/专属步长(%)，默认 5.00 |
| history_start | DATE | - | NULL | 历史数据开始日期（由 Stock.getWithHistoryRange 联表自动计算，非存储字段） |
| history_end | DATE | - | NULL | 历史数据结束日期（由 Stock.getWithHistoryRange 联表自动计算，非存储字段） |
| update_time | TIMESTAMP | - | CURRENT_TIMESTAMP | 价格更新时间 |

**索引**:

- PRIMARY KEY: `id`
- UNIQUE KEY: `uk_code` (`code`)

---

### 2.2 history_data (历史日 K 线行情明细表)

**表说明**: 存储各 ETF 历史日 K 线数据，供回测引擎调用。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | - | AUTO | 主键 ID |
| etf_code | VARCHAR | 20 | - | ETF 代码(联合唯一索引) |
| trade_date | DATE | - | - | 交易日期(联合唯一索引) |
| open_price | DECIMAL | 12,4 | 0.0000 | 开盘价 |
| close_price | DECIMAL | 12,4 | - | 收盘价 |
| high_price | DECIMAL | 12,4 | 0.0000 | 最高价 |
| low_price | DECIMAL | 12,4 | 0.0000 | 最低价 |
| volume | BIGINT | - | 0 | 成交量(股) |
| change_pct | DECIMAL | 10,4 | 0.0000 | 涨跌幅(%) |

**索引**:

- PRIMARY KEY: `id`
- UNIQUE KEY: `uk_etf_date` (`etf_code`, `trade_date`)

---

### 2.3 trade_records (交易流水与调仓日志表)

**表说明**: 记录回测过程中每一笔买卖调仓流水。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | - | AUTO | 主键 ID |
| trade_time | DATETIME | - | - | 交易时间 |
| trade_type | VARCHAR | 20 | - | 交易类型(init/rebalance/strategy_a/strategy_b) |
| etf_code | VARCHAR | 20 | - | ETF 代码 |
| trade_direction | VARCHAR | 10 | - | 交易方向(buy/sell) |
| shares | DECIMAL | 16,2 | - | 成交股数 |
| price | DECIMAL | 12,4 | - | 成交单价 |
| amount | DECIMAL | 16,2 | - | 成交金额 |
| fee | DECIMAL | 12,2 | 0.00 | 手续费 |
| before_ratio | DECIMAL | 10,4 | NULL | 交易前占比(%) |
| after_ratio | DECIMAL | 10,4 | NULL | 交易后占比(%) |
| reason | VARCHAR | 500 | NULL | 调仓原因说明 |
| trigger_detail | TEXT | - | NULL | 触发上下文 JSON |

**索引**:

- PRIMARY KEY: `id`
- INDEX: `idx_trade_time` (`trade_time`)
- INDEX: `idx_etf_code` (`etf_code`)

---

### 2.4 backtest_results (回测结果表)

**表说明**: 存储每次回测及参数寻优结果的量化指标。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | INT | - | AUTO | 主键 ID |
| name | VARCHAR | 200 | NULL | 回测记录名称（格式如"回测_2020-01-01_2026-01-01"） |
| params | JSON | - | NULL | 运行参数 JSON 字符串 |
| total_return | DECIMAL | 12,4 | NULL | 累计收益率(%) |
| annual_return | DECIMAL | 12,4 | NULL | 年化收益率(%) |
| max_drawdown | DECIMAL | 12,4 | NULL | 最大回撤(%) |
| annual_volatility | DECIMAL | 12,4 | NULL | 年化波动率(%) |
| sharpe_ratio | DECIMAL | 12,4 | NULL | 夏普比率 |
| daily_detail | LONGTEXT | - | NULL | 每日完整回测结果 JSON（寻优模式下为 NULL，单次精细回测时存储 result 对象的序列化字符串） |
| create_time | DATETIME | - | CURRENT_TIMESTAMP | 创建时间 |

**索引**:

- PRIMARY KEY: `id`
- INDEX: `idx_create_time` (`create_time`)

---

### 2.5 strategy_a_config (策略 A 档位配置表)

**表说明**: 存储策略 A 净值回撤分档策略各档位的偏离乘数配比。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | INT | - | AUTO | 主键 ID |
| trigger_type | ENUM | - | - | 触发类型(drawdown/rally) |
| level_order | INT | - | - | 档位级别(1/2/3) |
| threshold | DECIMAL | 10,4 | - | 触发阈值(%) |
| ratios | JSON | - | - | 资产偏离倍数/乘数 JSON，键为标的代码，值为专属步长整倍数(如 `{"161119": 2, "510880": -1}`)，每一档所有资产的 `倍数 × 专属步长` 累加和必须为 0% |
| update_time | TIMESTAMP | - | CURRENT_TIMESTAMP | 更新时间 |

**索引**:

- PRIMARY KEY: `id`
- UNIQUE KEY: `uk_type_level` (`trigger_type`, `level_order`)

---

### 2.6 strategy_b_config (策略 B 档位配置表)

**表说明**: 存储策略 B 年化收益率中枢偏离策略各档位的偏离乘数配比。

| 字段名 | 类型 | 长度 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | INT | - | AUTO | 主键 ID |
| deviation_type | ENUM | - | - | 偏离类型(overvalued/undervalued) |
| level_order | INT | - | - | 档位级别(1/2/3) |
| threshold | DECIMAL | 10,4 | - | 触发阈值(%) |
| ratios | JSON | - | - | 资产偏离倍数/乘数 JSON，键为标的代码，值为专属步长整倍数，每一档所有资产的 `倍数 × 专属步长` 累加和必须为 0% |
| update_time | TIMESTAMP | - | CURRENT_TIMESTAMP | 更新时间 |

**索引**:

- PRIMARY KEY: `id`
- UNIQUE KEY: `uk_type_level` (`deviation_type`, `level_order`)

## 3. 业务字段枚举说明

### 3.1 asset_type (资产类型)

| 值 | 说明 |
| --- | --- |
| 股票类 | 权益类 ETF（如沪深300、纳指） |
| 债券类 | 债券类 ETF（如国债、公司债） |
| 红利类 | 红利驱动 ETF |
| 商品类 | 商品类 ETF |
| 黄金类 | 黄金 ETF |

> **注意**: `etf-types` 接口返回系统现有 `asset_type` 去重列表与上述默认类型的并集，字段分字由使用者定义，不限于上述列表。

### 3.2 trade_type (交易类型)

| 值 | 说明 |
| --- | --- |
| init | 首日初始建仓 |
| rebalance | 日常再平衡调仓 |
| strategy_a | 策略 A 触发的加减仓 |
| strategy_b | 策略 B 触发的调仓 |

### 3.3 trade_direction (交易方向)

| 值 | 说明 |
| --- | --- |
| buy | 买入 |
| sell | 卖出 |

### 3.4 trigger_type (策略 A 触发类型)

| 值 | 说明 |
| --- | --- |
| drawdown | 回撤加仓（净值从高点下跌时买入） |
| rally | 反弹减仓（净值从低点反弹时卖出） |

### 3.5 deviation_type (策略 B 偏离类型)

| 值 | 说明 |
| --- | --- |
| overvalued | 高估减仓 |
| undervalued | 低估加仓 |

## 4. 索引使用建议

| 表名 | 关键索引 | 优化场景 |
| --- | --- | --- |
| stock | uk_code | ETF 代码精确查 |
| history_data | uk_etf_date, idx_etf_code | 按 ETF + 日期范围查询历史行情 |
| trade_records | idx_trade_time, idx_etf_code | 时间范围查询、按代码筛选流水 |
| backtest_results | idx_create_time | 按时间排序查询回测记录 |
| strategy_a_config | uk_type_level | 按触发类型 + 档位排序查询 |
| strategy_b_config | uk_type_level | 按偏离类型 + 档位排序查询 |

## 5. ER 关系说明

```
stock (1) ──── (N) history_data      # 一个 ETF 有多条历史 K 线
stock (1) ──── (N) trade_records    # 一个 ETF 代码关联交易流水
backtest_results        (独立表)         # 每次回测结果独立存储
strategy_a_config       (独立配置表)     # 策略 A 档位配置
strategy_b_config       (独立配置表)     # 策略 B 档位配置
```

> **说明**: `stock.history_start` 和 `history_end` 不是实存字段，而是由 `Stock.getWithHistoryRange()` 方法通过 LEFT JOIN history_data 并运算 MIN/MAX 自动计算返回的虚拟字段。

## 7. 维护建议

### 7.1 数据备份

```bash
# 备份数据库
mysqldump -u root -p etf > etf_$(date +%Y%m%d).sql

# 仅备份结构
mysqldump -u root -p --no-data etf > etf_schema.sql
```

### 7.2 数据清理

- `history_data` 表数据量较大时，建议按 ETF 代码分区存储
- `trade_records` 仅为回测结果记录，可随回测重跑而覆盖
- `backtest_results` 定期清理不需要的历史回测结果
