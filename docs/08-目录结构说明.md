# 目录结构说明

> 本文档详细说明项目的目录结构。项目采用 **web 与 desktop 两套完全独立的实现**，代码不共享，各自维护前端、后端、爬虫与量化指标计算。

## 顶层目录

```
etf/
├── web/           # web 网页版（BS 架构）：Express + MySQL，前后端分离
├── desktop/       # desktop 桌面版（CS 架构）：Electron + SQLite，开箱即用
├── docs/          # 项目文档
├── .gitignore     # Git 忽略配置
└── README.md      # 项目说明
```

> 不存在共享目录。web 与 desktop 各自独立，互不依赖。

## 详细拆解

### web/ 【BS 网页版，完全独立】

```
web/
├── client/                    # 前端 (Vue 3 + TS + Vite)，仅 HTTP 通信
│   ├── src/
│   │   ├── api/index.ts       # API 接口层
│   │   ├── components/Layout.vue  # 布局（网页侧边栏风格）
│   │   ├── router/index.ts    # 路由配置
│   │   ├── utils/
│   │   │   ├── electron-api.ts   # API 客户端（纯 HTTP 模式）
│   │   │   ├── http.ts           # axios 实例 + 拦截器
│   │   │   └── format.ts         # 格式化工具
│   │   ├── views/             # Backtest/Config/Strategy/History 4 个页面
│   │   ├── App.vue
│   │   └── main.ts
│   ├── vite.config.ts         # 含 /api 代理到 localhost:3001
│   └── package.json
└── server/                    # 后端 (Express + MySQL)
    ├── src/
    │   ├── index.js           # Express 入口，监听 3001
    │   ├── config/db.js       # MySQL 连接池 (mysql2/promise)
    │   ├── models/            # BaseModel ORM + 6 个数据模型
    │   ├── routes/            # RESTful 路由 (etf/backtest/config/records)
    │   ├── services/
    │   │   ├── backtest.js    # 回测引擎
    │   │   └── spider.js      # 爬虫模块（web 独立版）
    │   └── utils/
    │       ├── helpers.js     # 量化指标计算（web 独立版）
    │       ├── logger.js      # Winston 日志
    │       └── server.js      # 服务器工具
    ├── .env.demo              # 配置模板
    └── package.json
```

| 关键点 | 说明 |
|-------|------|
| 通信方式 | 前端通过 axios 走 HTTP API |
| 数据库 | MySQL，需先执行 `docs/database/init_tables.sql` |
| 爬虫 | `web/server/src/services/spider.js`（独立实现） |
| 量化指标 | `web/server/src/utils/helpers.js`（独立实现） |
| 启动 | `cd web/server && npm run dev` + `cd web/client && npm run dev` |

│   │   │   └── format.ts         # 格式化工具
│   │   ├── views/             # Backtest/Config/Strategy/History 4 个页面
│   │   ├── App.vue
│   │   └── main.ts

│   ├── TradeRecord.js

│   └── StrategyBConfig.js
├── services/
│   └── backtest.js            # 回测引擎（引用 ./utils.js）
├── assets/icon.png            # 应用图标
├── data/                      # SQLite 数据库（运行时生成，不在 git）

| 关键点 | 说明 |
|-------|------|
| 通信方式 | 前端通过 Electron IPC（`window.electronAPI`）与主进程通信 |
| 数据库 | SQLite，`database.js` 启动时自动建表，免安装 |
| 爬虫 | `desktop/spider.js`（独立实现） |
| 量化指标 | `desktop/utils.js`（独立实现） |
| 启动 | `cd desktop && npm run dev` |
| 打包 | `cd desktop && npm run dist`（产物在 `desktop/dist/`） |

## 架构对照表

| 功能模块 | web（BS） | desktop（CS） |
|---------|----------|--------------|
| **前端目录** | `web/client/` | `desktop/client/` |
| **前端通信** | HTTP（axios） | IPC（electronAPI） |
| **前端布局** | 侧边栏导航 | 顶部标签页导航 |
| **后端** | `web/server/`（Express） | `desktop/main.js`（Electron 主进程） |
| **数据库** | MySQL（mysql2） | SQLite（better-sqlite3） |
| **数据模型** | `web/server/src/models/`（BaseModel ORM） | `desktop/models/`（SQLite 直连） |
| **爬虫** | `web/server/src/services/spider.js` | `desktop/spider.js` |
| **量化指标** | `web/server/src/utils/helpers.js` | `desktop/utils.js` |
| **回测引擎** | `web/server/src/services/backtest.js` | `desktop/services/backtest.js` |
| **运行时数据** | MySQL 数据库 | `desktop/data/*.db` |
| **打包** | N/A | `desktop/dist/`（electron-builder） |

> 两套实现的爬虫和量化指标计算逻辑相同，但代码各自独立维护，不共享文件。

## 注意事项

1. **web 需配置 MySQL**：在 `web/server/` 下复制 `.env.demo` 为 `.env`，填入正确的数据库密码，并先执行 `docs/database/init_tables.sql` 建表。
2. **desktop 自包含**：`desktop/` 目录包含所有依赖和 SQLite 数据库，无需额外配置，`npm run dev` 即可运行。
3. **代码不共享**：web 与 desktop 是两套独立实现，修改一端的爬虫/量化指标代码不会影响另一端。如需同步算法变更，需分别修改 `web/server/src/services/spider.js` 与 `desktop/spider.js`（量化指标同理）。
4. **前端布局差异**：web 采用网页常见的侧边栏导航，desktop 采用桌面应用常见的顶部标签页导航，风格各自独立。
5. **desktop 打包路径**：`main.js` 在生产环境通过 `process.resourcesPath` 加载 `client/dist/index.html`，由 `package.json` 的 `extraResources` 配置复制。
