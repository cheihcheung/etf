# 多资产策略回测系统 · 使用手册

---

## 一、安装

1. 双击 `多资产策略回测系统_Setup.exe`
2. 按提示点「下一步」，选择安装位置
3. 点「安装」，等待完成
4. 桌面会出现快捷方式，双击打开

> 首次启动可能需要几秒钟加载，请耐心等待。

---

## 二、界面说明

打开后你会看到4个标签页，点击切换：

| 标签 | 功能 |
|------|------|
| **回测寻优** | 运行回测，查看收益图表 |
| **股票管理** | 添加/删除标的，同步数据，设置配比 |
| **策略配置** | 设置调仓策略的参数 |
| **历史走势** | 查看单个标的的K线走势 |

---

## 三、第一次使用：5步完成回测

### 第1步：添加你要回测的标的

1. 点击 **「股票管理」** 标签
2. 点击 **「添加股票」**，填写信息：

   - **代码**：如 `510300`（沪深300ETF）、`518880`（黄金ETF）
   - **名称**：如 `沪深300ETF`
   - **资产类型**：下拉选择（股票类/债券类/红利类/商品类/黄金类/指数类）
   - **缩小倍率**：一般填1就行
   - **对比基准**：选一个宽基指数打勾（建议沪深300），回测时自动对比

3. 点击 **「添加」**
4. 重复以上步骤，把你要回测的标的都加进来

### 第2步：同步历史数据

1. 点击 **「同步历史数据」** 按钮
2. 选择起止日期（建议从2010年开始，数据越多回测越准）
3. 数据源选 **「多源自动融合」**（推荐）
4. 点击 **「开始同步」**，等待完成

> 💡 同步时间取决于标的数量和日期范围，一般1-5分钟。

### 第3步：设置初始配比

在股票管理页面下方的表格中：

1. 打开每个标的的 **「启用」** 开关
2. 填写 **「初始占比(%)」**，比如：
   - 沪深300ETF → 40%
   - 中证500ETF → 30%
   - 国债ETF → 30%
3. 所有启用标的的占比之和不能超过100%
4. 想快速凑满100%，点某个标的的 **「补满」** 按钮
5. 点击 **「保存比例」**

### 第4步：运行回测

1. 点击 **「回测寻优」** 标签
2. 设置参数：
   - **日期区间**：选择你想回测的时间范围
   - **初始资金**：默认100万
   - **手续费率**：默认0.03%，一般不用改
3. 点击 **「单次回测」**
4. 等待几秒到几十秒，结果自动展示

### 第5步：看结果

回测完成后，下方会出现：

**指标表格**——一眼看关键数据：

| 指标 | 怎么看 |
|------|--------|
| 总收益率 | 整个区间赚了多少 |
| 年化收益率 | 折算成每年赚多少，这个最直观 |
| 最大回撤 | 最惨的时候跌了多少，越小越好 |
| 夏普比率 | 大于1算优秀，越大越好 |

**4张图表**——点击标签切换查看：

1. **收益对比曲线**：红线是你的策略，灰线是沪深300基准，红线在灰线上面就是跑赢了
2. **资产配置变动**：随着时间推移，你的钱在各标的和现金之间的分布变化
3. **回撤走势**：策略在什么时候跌得最惨，持续了多久
4. **历年盈亏**：每年赚了还是亏了，和基准对比

## 四、功能详解

### 4.1 同步行情

点击 **「同步行情」**，一键获取所有标的的最新价格和涨跌幅。不需要手动更新。

### 4.2 导入同花顺数据

如果你从同花顺下载了历史数据，可以直接导入：

1. 点击 **「导入历史数据」**
2. 点击 **「选择文件」**，选择你下载的 `.xls` 文件
3. 系统自动解析并显示预览
4. 在 **「导入到股票」** 选择目标标的
5. 点击 **「开始导入」**

> 同花顺下载方法：打开同花顺 → K线页面 → 右键 → 数据导出 → 保存为xls

### 4.3 策略配置

点击 **「策略配置」** 标签，可以设置两种调仓策略。

#### 策略A — 越跌越买（回撤加仓）

**大白话**：标的从高点跌到一定程度，就加仓；涨回来，就减仓。

**设置方法**：

1. 点 **「添加回撤档位」**，设置下跌时怎么加仓：
   - 跌 10% → 加仓 5%
   - 跌 20% → 加仓 10%

2. 点 **「添加反弹档位」**，设置上涨时怎么减仓：
   - 涨 8% → 减仓 5%
   - 涨 15% → 减仓 10%

3. **新高重置**：打开后，创新高时档位归零，重新计算回撤

**举例**：你持有沪深300ETF，初始配比30%。
- 沪深300从高点跌10% → 配比自动变成35%
- 继续跌到20% → 配比变成40%
- 之后反弹8% → 配比回到35%

#### 策略B — 涨多了卖、跌多了买（年化偏离）

**大白话**：以目标年化收益率为中心，实际收益超过太多就减仓，低于太多就加仓。

**设置方法**：

1. 填 **「中枢年化」**：你的目标年化，比如10%
2. 点 **「添加高估档位」**：涨太多时减仓
   - 年化超过15%（偏离+5%）→ 减仓5%
3. 点 **「添加低估档位」**：跌太多时加仓
   - 年化低于5%（偏离-5%）→ 加仓5%

### 4.4 在回测中启用策略

1. 回到 **「回测寻优」** 标签
2. 勾选你想启用的策略：**再平衡** / **策略A** / **策略B**
3. 选择 **调仓频率**：每月/每周/每日
4. 点击 **「单次回测」**

> 💡 建议先不勾选任何策略跑一次，再勾选策略跑一次，对比两种结果。

### 4.5 历史走势

点击 **「历史走势」** 标签：

1. 下拉选择一个标的
2. 选日期范围
3. 点 **「查询」**
4. 点 **「显示图表」** 看K线走势
5. 下方表格看逐日数据

### 4.6 查看历史回测记录

每次回测的结果都会保存。在回测寻优页面最下方的表格中，点击某条的 **「详情」** 可重新查看完整结果。

## 五、常见问题

**问：数据从哪来的？准确吗？**
从东方财富和腾讯财经获取，和你炒股软件上看到的基本一致。

**问：回测赚钱了，实盘一定能赚吗？**
不一定。回测是"用过去看过去"，不是预测未来。它的价值是帮你排除明显不行的策略。

**问：删了一个股票，它的历史数据还在吗？**
不在了，会一起删除。删之前想清楚。

**问：初始配比总和超过100%了怎么办？**
超过100%保存按钮会变灰，调低某个标的的占比就行。

**问：夏普比率多少算好？**
大于1算不错，大于2算优秀，越大越好。

**问：最大回撤-30%是什么意思？**
你的组合从最高点跌了30%。如果投了100万，最惨的时候只剩70万。看你自己能不能承受这个幅度。

**问：手续费率怎么填？**
ETF交易一般万分之三，填0.03就行。如果你的券商更贵，就填高一点。

## 六、术语速查

| 术语 | 大白话 |
|------|--------|
| 回测 | 用过去的数据模拟交易，看策略行不行 |
| 年化收益率 | 平均每年赚多少% |
| 最大回撤 | 最惨的时候亏了多少% |
| 夏普比率 | 承担1份风险换来多少收益，>1就是好的 |
| 再平衡 | 配比偏了就买卖调整回来 |
| 调仓 | 根据策略信号买入或卖出 |
| 基准 | 对比参照物，默认沪深300 |
| 净值 | 你的钱变成多少了，初始为1 |
