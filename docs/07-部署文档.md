## 2. desktop 桌面版部署（推荐，免数据库）

### 2.1 开发环境启动

```bash
cd desktop
npm install        # 安装依赖（含 better-sqlite3 原生模块编译）
npm run dev        # 启动开发模式（Vite + Electron）
```

- SQLite 数据库在 `desktop/data/etf.db` 自动创建，开箱即用。
- 前端通过 IPC 与 Electron 主进程通信，无需 HTTP 服务。
- 系统菜单已隐藏，默认不自动打开 DevTools（需调试时按 F12 手动打开）。

### 2.2 打包桌面应用

```bash
cd desktop
npm run dist       # 产物在 desktop/dist/
```

`package.json` 中 `electron-builder` 配置会自动：
- 构建 `desktop/client/` 前端到 `client/dist/`
- 通过 `extraResources` 将 `client/dist/` 复制到安装包 resources 目录
- 生产环境 `main.js` 通过 `process.resourcesPath` 加载静态文件

### 2.3 desktop 常见问题

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| better-sqlite3 编译失败 | Node 与 Electron 版本不匹配 | `npm run postinstall`（执行 electron-rebuild） |
| 端口 5173 被占用 | 其他 Vite 进程残留 | `netstat -ano \| findstr :5173` 查杀占用进程 |
| 数据库锁死 | WAL 文件异常 | 删除 `desktop/data/etf.db-shm` 和 `etf.db-wal` 后重启 |

## 3. web 网页版部署（需 MySQL）

### 3.1 克隆项目

```bash
git clone <repository-url>
cd etf
```

### 3.2 数据库初始化

创建数据库 `etf`，导入建表脚本：

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS etf CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
mysql -u root -p etf < docs/database/init_tables.sql
```

> **💡 底层热迁移支持**：系统内置了数据表 DDL 自动热迁移机制。后端程序在首次启动并成功心跳连接 MySQL 后，会自动检测并防重升级为 `stock` 表追加 `is_enabled`（是否启用）与 `step_ratio`（专属步长）两列，无需开发或运维手动执行复杂的 `ALTER TABLE` 物理修改。

### 3.3 后端启动

```bash
cd web/server
npm install

# 配置环境变量
cp .env.demo .env   # 按需修改数据库连接信息

# 启动开发服务器
npm run dev
```

服务默认监听 `http://localhost:3001`。

### 3.4 前端启动

```bash
cd web/client
npm install

# 启动开发服务器
npm run dev
```

默认地址 `http://localhost:5173`，自动代理 `/api` 请求到后端 3001 端口。

## 4. web 项目配置

### 4.1 数据库配置

数据库连接池配置路径：`web/server/src/config/db.js`

```javascript
const pool = mysql.createPool({
  host: process.env.DB_HOST || 'localhost',
  port: process.env.DB_PORT || 3306,
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '',
  database: process.env.DB_NAME || 'etf',
  connectionLimit: 10,
  queueLimit: 0,
});
```

可通过环境变量覆盖默认配置：

```bash
set DB_HOST=your_host
set DB_USER=your_user
set DB_PASSWORD=your_password
set DB_NAME=etf
```

### 4.2 后端端口

后端默认端口 3001，通过环境变量修改：

```bash
set SERVER_PORT=3001
```

### 4.3 前端代理配置

前端开发服务器通过 Vite 代理转发 API 请求：

```typescript
// web/client/vite.config.ts
server: {
  port: 5173,
  strictPort: true,
  proxy: {
    '/api': {
      target: 'http://localhost:3001',
      changeOrigin: true,
    },
  },
}
```

### 4.4 交易费率配置

| 参数 | 默认值 | 位置 |
| --- | --- | --- |
| feeRate | 0.0003 | 系统配置中的 `feeRate` |
| feeExemptFive | true | 系统配置中的 `feeExemptFive` |

## 5. web 生产环境部署

### 5.1 前端构建

```bash
cd web/client
npm run build
```

构建产物输出到 `web/client/dist/` 目录。

### 5.2 后端运行

```bash
cd web/server
NODE_ENV=production node src/index.js
```

建议使用 PM2 进程管理：

```bash
npm install -g pm2
pm2 start src/index.js --name etf-server
pm2 save
pm2 startup
```

### 5.3 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /path/to/web/client/dist;
    index index.html;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
    }

    # SPA 路由 fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 6. 常用命令

### 6.1 NPM 脚本

| 命令 | 说明 | 适用 |
| --- | --- | --- |
| `npm run dev` | 启动开发服务器 | web/desktop 通用 |
| `npm run build` | 生产构建 | web/client |
| `npm run dist` | 打包桌面应用 | desktop |

### 6.2 数据库操作（仅 web 版）

```bash
# 导出（备份）数据库
mysqldump -u root -p etf > backup.sql

# 导出无数据（仅结构）
mysqldump -u root -p --no-data etf > schema.sql

# 导入数据库
mysql -u root -p etf < backup.sql

# 导出表结构
mysqldump -u root -p --no-data etf stock history_data > tables.sql
```

### 6.3 PM2 管理（仅 web 版）

```bash
pm2 list                    # 查看进程列表
pm2 logs etf-server         # 查看日志
pm2 restart etf-server      # 重启服务
pm2 stop etf-server         # 停止服务
pm2 delete etf-server       # 删除进程
```

## 7. 故障排查

### 7.1 web 后端无法启动

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 端口冲突 | 端口 3001 被占用 | `netstat -ano \| findstr :3001` 查看占用进程 |
| 数据库连接失败 | MySQL 服务未启动 | `net start MySQL` 启动服务 |
| 数据库不存在 | 未创建 `etf` | `mysql -u root -p -e "CREATE DATABASE etf"` |
| 依赖缺失 | 未安装 npm 包 | `cd web/server && npm install` |
| 密码错误 | .env 配置有误 | 检查 `web/server/.env` 中的 DB_PASSWORD |

### 7.2 web 前端无法访问 API

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 404 Not Found | 代理配置错误 | 检查 `web/client/vite.config.ts` 中 proxy.target 是否为 `http://localhost:3001` |
| 连接超时 | 后端未启动 | 启动后端服务后刷新页面 |
| CORS 错误 | 后端 CORS 配置未生效 | 确认 `web/server/src/index.js` 中已配置 cors 中间件 |
| 数据为空 | 接口地址变更 | 浏览器 F12 → Network 面板查看请求实际 URL |

### 7.3 desktop 启动失败

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| better-sqlite3 报错 | 原生模块版本不匹配 | `cd desktop && npm run postinstall` 重新编译 |
| 端口 5173 被占用 | web/client 或其他进程占用 | `netstat -ano \| findstr :5173` 查杀进程 |
| 白屏 | 前端未构建（生产模式） | `cd desktop/client && npm run build` |
| 数据库异常 | SQLite 文件损坏 | 删除 `desktop/data/etf.db` 重启自动重建 |

### 7.4 行情数据为空（通用）

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 实时行情为空 | 未执行同步 | 在页面点击"同步行情"按钮 |
| 历史 K 线为空 | 未同步历史数据 | 点击"同步历史"输入 ETF 代码 |
| 同步失败 | 网络限制 | 确认服务器可访问腾讯/东方财富 API |
| 数据不更新 | 缓存 | 强制刷新页面(Ctrl+F5) |

### 7.5 配置不生效（通用）

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 修改比例后回测仍用旧值 | 未保存配置 | 确认点击了"保存"按钮 |
| 策略 A/B 配置未生效 | 档位未启用 | 检查档位开关是否开启 |
| 回测结果与预期不符 | 参数未同步 | 重新保存配置后再运行回测 |
