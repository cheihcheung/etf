## 2. 快速启动（开发环境）

### 2.1 克隆项目

```bash
git clone <repository-url>
cd etf
```

### 2.2 数据库初始化

创建数据库 `etf_strategy`，导入建表脚本：

```bash
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS etf_strategy CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;"
mysql -u root -p etf_strategy < database/backtest_results.sql
```

> **💡 底层热迁移支持**：系统内置了数据表 DDL 自动热迁移机制。后端程序在首次启动并成功心跳连接 MySQL 后，会自动检测并防重升级为 `etf_basic` 表追加 `is_enabled`（是否启用）与 `step_ratio`（专属步长）两列，无需开发或运维手动执行复杂的 `ALTER TABLE` 物理修改。

### 2.3 后端启动

```bash
cd server
npm install

# 启动开发服务器
npm run dev
```

服务默认监听 `http://localhost:3001`。

### 2.4 前端启动

```bash
cd client
npm install

# 启动开发服务器
npm run dev
```

默认地址 `http://localhost:8088`。

## 3. 项目配置

### 3.1 数据库配置

数据库连接池配置路径：`server/src/config/db.js`

```javascript
const pool = mysql.createPool({
  host: process.env.DB_HOST || 'localhost',
  port: process.env.DB_PORT || 3306,
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '',
  database: process.env.DB_NAME || 'etf_strategy',
  connectionLimit: 10,
  queueLimit: 0,
});
```

可通过环境变量覆盖默认配置：

```bash
set DB_HOST=your_host
set DB_USER=your_user
set DB_PASSWORD=your_password
set DB_NAME=etf_strategy
```

### 3.3 后端端口

后端默认端口 3001，通过环境变量修改：

```bash
set SERVER_PORT=3001
```

### 3.4 前端代理配置

前端开发服务器通过 Vite 代理转发 API 请求：

```typescript
// client/vite.config.ts
server: {
  port: 8088,
  proxy: {
    '/api': {
      target: 'http://localhost:3001',
      changeOrigin: true,
    },
  },
}
```

### 3.5 交易费率配置

| 参数 | 默认值 | 位置 |
| --- | --- | --- |
| feeRate | 0.0003 | `global_config` 表中的 `fee_rate` |
| feeExemptFive | true | `global_config` 表中的 `fee_exempt_five` |

## 4. 生产环境部署

### 4.1 前端构建

```bash
cd client
npm run build
```

构建产物输出到 `client/dist/` 目录。

### 4.2 后端运行

```bash
cd server
NODE_ENV=production node src/index.js
```

建议使用 PM2 进程管理：

```bash
npm install -g pm2
pm2 start src/index.js --name etf-server
pm2 save
pm2 startup
```

### 4.3 Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    root /path/to/client/dist;
    index index.html;

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
    }

    # SPA 路由 fallback
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

| `npm run build` | 生产构建 |

### 5.2 数据库操作

```bash
# 导出（备份）数据库
mysqldump -u root -p etf_strategy > backup.sql

# 导出无数据（仅结构）
mysqldump -u root -p --no-data etf_strategy > schema.sql

# 导入数据库
mysql -u root -p etf_strategy < backup.sql

# 导出表结构
mysqldump -u root -p --no-data etf_strategy etf_basic etf_history > tables.sql
```

```bash
pm2 stop etf-server         # 停止服务
pm2 delete etf-server       # 删除进程
```

## 6. 故障排查

### 6.1 后端无法启动

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 端口冲突 | 端口 3001 被占用 | `netstat -ano | findstr :3001` 查看占用进程 |
| 数据库连接失败 | MySQL 服务未启动 | `net start MySQL` 启动服务 |
| 数据库不存在 | 未创建 `etf_strategy` | `mysql -u root -p -e "CREATE DATABASE etf_strategy"` |
| 依赖缺失 | 未安装 npm 包 | `cd server && npm install` |
| SQL 文件错误 | 建表语句执行失败 | 检查 `database/backtest_results.sql` 语法 |

### 6.2 前端无法访问 API

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 404 Not Found | 代理配置错误 | 检查 `vite.config.ts` 中 proxy.target 是否为 `http://localhost:3001` |
| 连接超时 | 后端未启动 | 启动后端服务后刷新页面 |
| CORS 错误 | 后端 CORS 配置未生效 | 确认 `server/src/index.js` 中已配置 cors 中间件 |
| 数据为空 | 接口地址变更 | 浏览器 F12 → Network 面板查看请求实际 URL |

### 6.3 行情数据为空

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 实时行情为空 | 未执行同步 | 在页面点击"同步行情"按钮 |
| 历史 K 线为空 | 未同步历史数据 | 点击"同步历史"输入 ETF 代码 |
| 同步失败 | 网络限制 | 确认服务器可访问东方财富 API |
| 数据不更新 | 缓存 | 强制刷新页面(Ctrl+F5) |

### 6.4 配置不生效

| 现象 | 可能原因 | 解决方案 |
| --- | --- | --- |
| 修改比例后回测仍用旧值 | 未保存配置 | 确认点击了"保存"按钮 |
| 策略 A/B 配置未生效 | 档位未启用 | 检查档位开关是否开启 |
| 回测结果与预期不符 | 参数未同步 | 重新保存配置后再运行回测 |
