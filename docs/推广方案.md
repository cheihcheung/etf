## 第二章：抖音视频实操（手把手教你做）

### 2.1 视频制作完整流程

```
第1步：写文案（5分钟）
  ↓
第2步：录操作画面（5分钟）
  ↓
第3步：录配音（3分钟）
  ↓
第4步：剪映合成（10分钟）
  ↓
第5步：发布+写标题和标签（3分钟）
```

**每条视频总耗时约 25-30 分钟**

### 2.2 录操作画面的具体方法

1. 打开软件，调大窗口（让内容更清晰）
2. 按 `Win+G`，点「录制」
3. 按文案描述的操作一步步做
4. 做完后按 `Win+Alt+R` 停止
5. 视频自动保存到 `C:\Users\你的用户名\Videos\Captures`

> **技巧**：操作慢一点，每点一个按钮停顿1秒，方便后期剪辑。关键数据出现时停留2-3秒。

### 2.3 录配音的方法

**最简单的方式：手机录音**
1. 打开手机录音APP
2. 把文案念一遍，语速偏快、有激情
3. 念完保存，传到电脑

**更好的方式：直接在剪映里配**
1. 打开剪映，导入录屏画面
2. 点「音频」→「录音」
3. 看着画面同步配音

### 2.4 剪映合成的具体操作

1. 打开剪映 → 「开始创作」→ 导入录屏视频
2. 把视频裁成竖屏：点「比例」→ 选 9:16
3. 画面缩放：双指捏合，让软件界面充满屏幕
4. 导入配音：点「音频」→「导入音乐」→ 选择录音文件
5. 对齐画面和声音：拖动音轨，让配音和操作同步
6. 加字幕：点「文字」→「识别字幕」→ 自动生成 → 检查修正
7. 加背景音乐：点「音频」→「音乐」→ 搜"科技"或"商务"→ 选一个 → 音量调到10%
8. 关键数据加标注：在收益数字出现时，点「贴纸」→「箭头」或「气泡」→ 指向数字
9. 导出：选 1080P → 导出

- 转化率低 → 没说清楚怎么获取工具，置顶评论要更显眼

## 第九章：常见问题

**Q：我完全不会剪辑，能做吗？**
能。剪映是傻瓜式操作，导入视频→识别字幕→导出，5分钟就学会了。实在不行就用图文发小红书，连剪辑都不用。

**Q：抖音号刚开始没有流量怎么办？**
前2周是正常的，抖音需要时间识别你的内容标签。坚持发，不要断更。多在同领域视频下评论互动，帮助算法认识你。

**Q：视频没人看怎么办？**
1. 检查标题够不够吸引（要有痛点或数据）
2. 前3秒有没有钩子
3. 换个发布时间（晚上8-10点流量最大）
4. 同一个内容换不同标题发第2次

**Q：要不要投DOU+？**
前期不建议。先靠自然流量测出哪类内容播放好，再考虑给好内容投DOU+放大。

**Q：要不要找博主合作？**
等你做到2000粉以后再考虑。先把自己账号做起来，有了基础数据才有谈合作的资本。
