## 3. API 调用规范

### 3.1 Axios 封装

```typescript
// utils/request.ts
import axios from 'axios'

const request = axios.create({
  baseURL: '/api',
  timeout: 30000,
})

request.interceptors.response.use(
  (response) => response.data,
  (error) => Promise.reject(error)
)

export default request
```

### 3.2 API 模块结构

```typescript
// api/config.ts
import request from '../utils/request'

export const configApi = {
  getGlobal: () => request.get('/config/global'),
  updateGlobal: (data: Record<string, any>) => request.put('/config/global', data),
  getStrategyA: () => request.get('/config/strategy-a'),
  saveStrategyA: (data: any) => request.post('/config/strategy-a', data),
  getStrategyB: () => request.get('/config/strategy-b'),
  saveStrategyB: (data: any) => request.post('/config/strategy-b', data),
  getRebalance: () => request.get('/config/rebalance'),
  saveRebalance: (data: any) => request.post('/config/rebalance', data),
  getInitialRatios: () => request.get('/config/initial-ratios'),
  updateInitialRatios: (data: any) => request.put('/config/initial-ratios', data),
}
```

## 4. 页面功能说明

### 4.1 回测页面 (Backtest.vue)

- 路径: `/backtest`
- 功能: 执行历史回测、查看回测结果、参数寻优
- 核心组件: 回测参数表单、结果图表(ECharts)

### 4.2 ETF 配置页 (EtfConfig.vue)

- 路径: `/etf-config`
- 功能: ETF 标的增删改查、行情同步、历史数据同步
- 子组件: `EtfRatioConfig.vue`(初始配比管理)

### 4.3 策略配置页 (StrategyConfig.vue)

- 路径: `/strategy-config`
- 功能: 策略 A/B 参数配置、再平衡配置、全局参数配置
- 核心交互: 动态档位增删、各 ETF 占比实时校验

### 4.4 历史 K 线页 (EtfHistory.vue)

- 路径: `/etf-history`
- 功能: 查看任意 ETF 的历史 K 线走势及回测调仓标记

## 7. 编码规范

### 7.1 通用规则

- 使用 Composition API (`<script setup lang="ts">`)
- 组件名使用 PascalCase
- 模板中使用 kebab-case 引用组件
- 避免在模板中编写复杂逻辑

### 7.2 样式规范

- 使用 scoped 样式隔离
- 颜色使用 Element Plus 主题变量
- 布局优先使用 Flex/Grid
- 响应式适配使用 Element Plus 的响应式布局

### 7.3 性能优化

- 大数据列表使用虚拟滚动
- 图表组件按需加载
- 路由懒加载
- 避免不必要的响应式数据
